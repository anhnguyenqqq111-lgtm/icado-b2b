# Generating Outlines for Everest Logistics

Skill này chịu trách nhiệm lắp ráp và xuất bản Outline chuẩn Bảng (Table Format) cho thương hiệu **Everest Logistics**.

## Các bước lắp ráp Outline:
1. **Nạp dữ liệu**: Đọc `everest-outline-rules`, kết quả cào Top 3-5 đối thủ logistics và dữ liệu từ khóa.
2. **Khởi tạo Header**: Sử dụng form chuẩn bị thông tin:
   ```markdown
   # Outline: [Title B2B Logistics ≤ 60 chars]

   | Field | Value |
   |---|---|
   | Title | [Title B2B] |
   | Meta | [130-160 chars] |
   | KW chính/phụ | [Liệt kê] |
   | Target Audience | Doanh nghiệp XNK, Trưởng phòng Logistics/Procurement |
   | Hard rules | Tuân thủ 100% quy chuẩn Incoterms 2020 & Luật Hải quan |
   ```
3. **Lắp ráp 3 Bảng bắt buộc**:
   - `Keyword Strategy Table` (5 trường)
   - `Competitor Analysis Table` (7 cột có quote live)
   - `Outline Candidate Table` (8 cột, nội dung dạng bullet)
4. **Lồng ghép H2 Dịch vụ & Chữ ký Everest Logistics**.
5. **Kiểm tra QA Score** $\ge 80$.
